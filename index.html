American Rules Point Matrix

Points are automatically extracted from losers and paid directly to the winner based on official National Mah Jongg League rules:

  • 👉 Win via Discard: Discarder pays 2× hand value. Other players pay 1× hand value. Winner receives total combination.
  • 👉 Win via Self-Pick: All three losing players pay double (2×) the value of the hand to the winner.
  • 👉 Jokerless Bonus: Doubles all payouts entirely (except for singles/pairs hands which inherently lack jokers).
  • 👉 Exposed Penalties: Error infractions apply standalone point deductions without shifting active table positions or dealer winds.
